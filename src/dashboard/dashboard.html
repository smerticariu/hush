        My filters

        One filter per line, in uBlock Origin / Adblock Plus syntax. Elements you hide with “Hide an element” show up here too.

        Syntax cheat sheet
        ||ads.example.com^
        Block every request to that domain
        example.com##.banner
        Hide elements matching a CSS selector on one site
        ##.sponsored
        Hide them on every site
        example.com##div:has-text(Sponsored)
        Hide elements that contain some text
        @@||example.com^$document
        Allow everything on a site
        ! a comment
        Ignored

        About Hush

        Hush collects nothing. There is no server, no analytics and no account. Blocking happens inside Chrome, and your stats never leave this computer. Your settings sync between your own computers through Chrome Sync.

        Hush uses the same community filter lists as the best blockers: EasyList, EasyPrivacy, the uBlock Origin lists, Brave's public lists and ROList, plus its own fixes. The lists are refreshed every few days with new versions.
